# Контроль доступа

Приложение на React и TypeScript. HOC withAuthorization проверяет роли текущего пользователя.
Роли admin и editor открывают защищённый раздел. В остальных случаях отображается отказ в доступе.
Пользователя можно выбрать из списка. Context API не используется.

Для запуска:

```bash
npm install
npm run dev
```

Откройте адрес из терминала.
